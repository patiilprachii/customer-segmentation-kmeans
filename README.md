# Customer Segmentation using K-Means Clustering

## 📌 Objective
The objective of this project is to segment customers based on their purchasing behavior using Machine Learning techniques. This helps businesses understand different types of customers and create targeted marketing strategies.

---

## 📊 Problem Statement
Customers differ in terms of income, spending habits, and loyalty. It becomes difficult for businesses to treat all customers the same way.  
This project groups customers into different segments based on their similarities.

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

---

## 📁 Dataset
The dataset contains customer details such as:
- Age
- Annual Income
- Purchase Amount
- Purchase Frequency
- Loyalty Score
- Region

---

## ⚙️ Steps Involved

### 1. Data Loading
- Loaded dataset using Pandas

### 2. Data Cleaning
- Checked for missing values
- Removed duplicates

### 3. Exploratory Data Analysis (EDA)
- Visualized income distribution
- Analyzed purchase patterns

### 4. Feature Selection
Selected important features:
- Annual Income
- Purchase Amount
- Purchase Frequency
- Loyalty Score

### 5. Data Scaling
- Applied StandardScaler to normalize data

### 6. Model Building
- Used K-Means Clustering algorithm

### 7. Elbow Method
- Determined optimal number of clusters

### 8. Clustering
- Segmented customers into different groups

---

## 📈 Output
- Elbow graph to find optimal clusters
- Scatter plot showing customer segments
- Dataset with assigned cluster labels

---

## 🎯 Results
The model successfully grouped customers into different clusters based on their behavior, helping identify:
- High-value customers
- Low-value customers
- Medium segments
